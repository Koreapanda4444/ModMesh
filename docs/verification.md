# 검증 범위

- 01~12: 패키지 빌드, Ruff, 엄격한 mypy, Qt 이벤트 루프, HTTP health, SQLite 영속성/롤백/동시 접근, 식별·해시·어댑터 계약과 탐지 엔진 직접 실행을 검증했습니다. Windows/Ubuntu CI는 각 푸시에서 별도로 확인합니다.
- 13 Palworld: 임시 Steam 메타데이터에서 여러 라이브러리, App ID, 빌드 ID, 수동 경로, 잘못된 파일/경로 거부를 검증했습니다. **실제 Palworld Steam 설치와 게임 실행은 미검증**입니다. 의미상 게임 버전을 Steam build ID로 추측하지 않습니다.
- Windows 독립 실행 파일/설치 패키지의 배포 검증은 아직 수행하지 않았습니다. 현재 CI는 Python 패키지와 offscreen Qt 실행을 검증합니다.

- 14 Palworld 모드 탐지: `~mods`, `LogicMods`의 Pak/IoStore 파일 묶음, 두 UE4SS Mods 배치, 설정상의 활성 여부, 로더 DLL 존재, 외부 파일·심볼릭 링크 보호를 임시 디렉터리에서 검증했습니다. 파일은 읽기 전용이며 전부 외부 설치로 분류합니다. 루트의 게임 기본 Pak이나 사용자 지정 중앙 UE4SS 작업 폴더는 자동으로 모드라고 분류하지 않습니다. **실게임에서의 실제 로딩·호환성은 미검증**입니다.

UE4SS 배치/활성 설정 근거: [공식 설치 문서](https://docs.ue4ss.com/installation-guide.html), [공식 모드 설치 문서](https://docs.ue4ss.com/guides/installing-a-c%2B%2B-mod.html). DLL·파일 존재와 설정의 활성 값은 실행 중 로딩 성공을 의미하지 않습니다.

- 15 공통 HTTP: 실제 Modrinth HTTPS JSON 응답(로더 29개)을 확인했습니다. 주입한 HTTP transport로 재시도·잘못된 JSON·크기 제한·타임아웃·출처/인증 헤더 격리·긴 Retry-After 조기 재시도 방지를 검증했습니다. 소스 API 키는 환경 변수에서만 읽고 로그 마스킹에 등록합니다.

- 16 Nexus: 최신 [공식 v3 명세](https://api.nexusmods.com/openapi.yaml)의 공개 trending feed에서 실제 Palworld 프로젝트 3개를 조회했습니다. 전체 카탈로그 텍스트 검색과 버전/로더 필터로 가장하지 않고 제한된 feed임을 결과에 표시하며 공식 사이트로 인계합니다. 상세·파일은 공식 문서가 연결하는 v1 API를 사용합니다. API 키/계정 권한에 따른 메타데이터 파싱과 다운로드/인계 분기는 주입 transport로 검증했습니다. **인증 API와 실제 Nexus 파일 다운로드는 API 키가 없어 미검증**입니다. 버전·의존성·해시가 확인되지 않으면 미확인 상태를 유지합니다.

- 17 Modrinth: 실제 API에서 Sodium 검색·상세·Minecraft 1.21.1/Fabric 버전 22개·SHA-512/SHA-1 파일 식별·다운로드 URL 재조회와 Iris 의존성 선언을 검증했습니다. 게임 버전/로더는 API 필터와 응답 모델에 보존합니다. 모드팩 등 다른 프로젝트 유형과 다른 프로젝트의 파일은 거부합니다. 파일명만 있는 의존성은 해결된 것으로 간주하지 않고 미해결 선언으로 보존합니다. 실제 파일 저장/캐시 검증은 아래 23~24 항목에 기록했습니다.

- 18 CurseForge: [공식 API 명세](https://docs.curseforge.com/rest-api/)에 따라 Minecraft Java(game 432, mod class 6)만 활성화했습니다. 주입 transport로 검색 필터·페이지·버전/로더·해시·의존성·배포 권한 거부·다운로드 URL 부재·키 없는 호출 차단을 검증했습니다. Tool/Include 관계는 임의로 required/embedded로 바꾸지 않고 원래 관계를 보존합니다. CDN URL을 추측하거나 배포 제한을 우회하지 않습니다. **승인된 API 키가 없어 실제 인증 API·파일 다운로드는 미검증**입니다. Palworld/ARK 등 검증되지 않은 CurseForge 게임 매핑은 활성화하지 않았습니다.

- 19 통합 검색: 실제 CLI에서 Sodium 검색 결과를 받으면서 CurseForge 키 부재와 Nexus의 미지원 버전/로더 필터를 각 출처의 `unavailable` 상태로 분리했습니다. 취소 시 하위 요청 정리, 타임아웃·status 오류·잘못된 자격 증명의 출처별 격리와 독립적인 페이지 커서를 검증했습니다. 이름이 같다는 이유로 출처 결과를 자동 병합하지 않습니다.

- 20 출처 간 동일성: 동일 이름만으로 병합하지 않으며 작성자 레이블/작성자 제공 저장소가 함께 맞아도 미확정 후보로만 표시합니다. 명시적인 근거로 확인한 매핑만 Canonical ID로 묶습니다. 후보 거절, 매핑 영속성, 수동 분리 및 검색 CLI의 미확정 그룹 출력을 검증했습니다. 실제 인증이 필요한 다른 출처와의 모드 동일성을 임의로 확정하지 않았습니다.

- 21 동일 파일 후보: 같은 게임/확인된 게임 버전·로더, 공통 SHA-256/SHA-512, 충돌 없는 체크섬/크기인 경우만 병합합니다. 다른 버전명만으로 동일성을 판단하지 않으며, 이름/MD5/SHA-1만 일치하거나 맥락 미확인·해시 충돌·공통 강한 해시 없는 추이적 연결은 병합하지 않는 것을 검증했습니다. 여기서는 출처가 제공한 예상 해시를 비교하며 실제 바이트 검증은 다운로드에서 수행합니다.

- 22 출처 우선순위: 게임별 설정과 실제 Minecraft CLI 결과 순서를 확인했습니다. API/권한상 이용 가능한 동일 파일 후보만 대체 출처로 선택하며, 선택한 버전·의존성 컨텍스트는 원래 요청에 고정합니다. 출처 장애·우선순위 변경·출처 고정·해시/호환성 미확인 후보 거부를 검증했습니다. 플랫폼 권한은 각 어댑터가 다운로드 URL을 결정할 때 다시 확인합니다.

- 23 다운로드: 실제 Modrinth의 Sodium `SMxNOGZ6` 파일 1,574,609바이트를 스트리밍 저장하고 출처 SHA-512/SHA-1과 로컬 SHA-256(`3d43c14985a4deb19c654aad3393b454cf57e1ebcbba86c4ae6a98dfc60eca2d`)을 검증했습니다. 실행 환경의 OS DNS 제한 때문에 이 실네트워크 확인은 Google 공개 DoH 응답을 주입한 resolver로 수행했습니다. 제품 기본 경로는 OS DNS이며, 임의 IP를 허용하도록 우회하지 않았습니다. 임시 transport로 연결 중단 후 처음부터 재시도·해시 실패 미게시·기존/늦게 생성된 파일 보호·실행/대기 취소·임시 파일 정리·사설 IP/외부 리다이렉트 차단을 검증했습니다. 실제 바이트가 틀린 첫 출처에서 강한 동일 파일 근거가 있는 두 번째 출처로 전환하고 원래 버전/파일 ID를 유지하는 것도 확인했습니다. 파일 손상 위험 회귀 방지를 위해 `tools/verify_safety.py`만 CI에 추가했습니다. Nexus/CurseForge 실다운로드는 여전히 인증 미검증입니다.

- 24 캐시: 같은 실제 Sodium 파일을 요청해 첫 요청만 다운로드(`network_fetches=1`)하고 두 번째 요청은 SHA-256 및 출처 체크섬 재검증 후 캐시를 사용했습니다. 별도 CLI 프로세스의 pinned-version 다운로드도 `cache_hit=true`로 내보냈고, `info`/`verify`/`prune`/`clear` 실행 후 내보낸 1,574,609바이트 복사본이 남는 것을 확인했습니다. 실네트워크 최초 다운로드에는 23번과 같은 DoH resolver 조건을 사용했습니다. 임시 실행으로 별도 프로세스의 단일 다운로드 잠금, 강한 동일 해시의 다른 native ID 재사용, 변조 거부와 재다운로드, 용량/LRU 정리, 취소와 잠금 해제, 설정 검증, 심볼릭 링크·inode 교체·미등록 파일 보호를 확인했습니다. 게시 전/후에 하위 프로세스를 강제 종료해, 누락 객체는 miss로 복구하고 게시된 객체는 재검증해 재사용하는 것도 확인했습니다. 크래시로 생긴 미등록 임시 파일은 안전 근거 없이 자동 삭제하지 않습니다. 설치 작업 저널/게임 복구는 후속 설치 단계의 범위입니다.

현재 검증은 Python wheel과 CLI/Qt 기본 이벤트 루프/FastAPI health, 임시 파일 기반 안전 검증입니다. 실제 게임 모드 설치·로딩, Windows 독립 실행 패키지, Nexus/CurseForge 승인 계정 API는 이 범위에 포함되지 않으며 완료로 처리하지 않았습니다.
